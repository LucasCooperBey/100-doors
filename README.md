## Gift types

| Type | What you get |
|---|---|
| 🧰 Tool or app | A repo you clone and run. Its README has a quick start, an example and its limits. |
| 🧩 Skill | A Claude Code skill folder you copy into `~/.claude/skills`. |
| 🪝 Hook | A Claude Code hook: a short script that runs before or after a tool call. |
| 🔌 MCP server | A server you add to Claude Code or another MCP client. |
| 📐 Pattern + engine | A written pattern with a small reference engine you can run. |
| 📝 Template, 💬 Prompt | A file in [`gifts/`](gifts) you fill in or paste into any chat. Used when the thing behind the door is private or lives in a vendor dashboard. |
| 🗂️ Directory | A live site plus the card behind every listing. |
