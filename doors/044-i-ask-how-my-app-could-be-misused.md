## What it is

I ask how my app could be misused before someone else finds out. threat-model traces risks through the actual code, with file and line evidence. It documents risks. It does not certify that an app is secure.

It needs the real repository and a scoped attacker model. It finds and documents risks. It does not block attacks.

It is adapted from OpenAI's security-threat-model skill, Apache-2.0 licensed; the folder carries that license and its Source section says what changed.
