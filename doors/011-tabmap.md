# Door 11: TabMap: why 200 tabs are open

- **Date:** October 23, 2026
- **Built:** December 30, 2025
- **Room:** 2
- **Code:** [LucasCooperBey/tabmap](https://github.com/LucasCooperBey/tabmap)

## What it is

Every tab tool saves a list of URLs you never open again. You do not have a tab problem. You have an unfinished-decisions problem.

TabMap reads your open Chrome tabs locally, groups them by project, labels why each one is open, flags which ones are stale or already solved, and prints a dry-run cleanup table before it closes anything. Banking, healthcare, email, and auth tabs are skipped at capture so they never touch disk.

## Try it today

1. Clone [LucasCooperBey/tabmap](https://github.com/LucasCooperBey/tabmap).
2. Run a dry run first on your open Chrome tabs to see why each tab is open and which ones are stale.
