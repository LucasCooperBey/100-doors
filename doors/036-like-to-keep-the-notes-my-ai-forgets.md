# Door 36: I like to keep the notes my AI forgets: save working notes to a file your session can read back

- **Date:** November 20, 2026
- **Built:** June 20, 2026
- **Room:** Memory (2 of 7)
- **Gift:** [scratchpad](https://github.com/LucasCooperBey/claude-skills/tree/main/skills/scratchpad)

## What it is

In a long chat, decisions made earlier slip out of view. scratchpad saves working notes to a file when you ask, so a later session can read them back.

It writes only when asked. It is not an automatic autosave or a session-start hook. Notes go in `.scratchpad.md` in the project root. Add that file to your `.gitignore` if you do not want it committed.
