# Door 31: I like listening to my agent's replies: hear an action-first summary instead of reading it all

- **Date:** November 14, 2026
- **Built:** June 21, 2026
- **Room:** 4
- **Gift:** [earshot](https://github.com/LucasCooperBey/earshot)

## What it is

A long agent reply can bury the one thing it needs from you. earshot turns the last reply into a short spoken summary, action first, using Ollama and a local model on your machine. Nothing leaves the machine. In Claude Code it installs as /. (summary) and /say (raw).

It needs Python, jq, curl, Ollama and a local model. The built-in system voice works with no extra setup.
