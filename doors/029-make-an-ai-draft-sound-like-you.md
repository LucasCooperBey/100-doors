## What it is

An AI draft can say what you mean in words you would never use. writing-check is one Python file with no dependencies. It lists the phrases that make a draft read as machine-written, each with its line and the rule behind it, and gives a weighted rate per 1,000 words. It ships a Claude Code Stop hook and a git pre-commit hook.

A checker can flag patterns. It cannot decide whether a claim is true or whether a sentence sounds like you.
