## What it is

I click a button instead of typing a command. A checklist page can say what to run, but it cannot run it. tap-server is a small server for your own machine. Buttons on a page you open from disk run commands from a list you wrote, and nothing else.

It listens on your own machine only, so other machines on the network cannot connect.

## Try it today

**The gift:**

[https://github.com/SanDiegoAIStudio/tap-server](https://github.com/SanDiegoAIStudio/tap-server)

Clone SanDiegoAIStudio/tap-server, run python3 -m unittest discover -s tests -q, copy commands.example.json to run/commands.json, start the server with python3 tap_server.py, and open demo.html from the same folder.
